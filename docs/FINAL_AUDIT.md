## Important verification boundary

The project deliberately contains **no Power BI dashboard** and makes no claim that an interactive
BI dashboard was opened, refreshed, or visually verified. The 12 PNG files in `screenshots/` are
static charts generated by `python/05_build_charts.py`, so they are reproducible from the repository.

## Data separation

The Olist marketplace dataset and the Marketing Campaign dataset are separate businesses and are
never joined. This is enforced in the SQL model and documented in `docs/METHODOLOGY.md`.

## Privacy

The committed Olist review and seller files are the prepared versions described in
`data/raw/README.md`. Review free-text columns containing personal contact information were removed,
and the affected seller-city value was masked. The project does not use those fields analytically.

## Reproducibility fix

An earlier version of `run_all.sh` regenerated the Excel workbook with openpyxl but did not
recalculate its formula caches unless an environment-specific helper was supplied. That meant a
fresh rebuild could produce a workbook that looked structurally correct but could not be independently
verified from cached values.

This has been fixed. `run_all.sh` now calls the portable
`python/09_recalc_excel.py`, which uses LibreOffice/soffice on PATH and fails clearly if a
recalculation engine is unavailable. The exact `run_all.sh` workflow was then executed from a clean
extraction and produced **1,437 cached formula values with 0 blank and 0 error cells**; the verifier
then passed **69/69 checks**.
